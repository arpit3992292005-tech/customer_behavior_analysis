# 📊 Data Analytics Project

## Overview

This project demonstrates a complete end-to-end data analytics workflow using Python, SQL, Power BI, and Gamma. It covers data loading, exploratory data analysis (EDA), data cleaning, SQL-based business analysis, interactive dashboard creation, and presentation of key insights. The objective is to transform raw data into meaningful business intelligence that supports data-driven decision-making.

---

## Dataset

The dataset contains structured business data with multiple attributes used for analysis and visualization. It was imported into Python for preprocessing, stored in SQL for querying, and connected to Power BI for dashboard development.

---

## Tools & Technologies

* **Python** – Data loading, preprocessing, and exploratory data analysis
* **Pandas & NumPy** – Data manipulation and cleaning
* **Matplotlib & Seaborn** – Data visualization
* **SQL (MVSQL/PostgreSQL)** – Data storage and business queries
* **Power BI** – Interactive dashboard creation
* **Gamma** – Professional presentation of insights
* **Jupyter Notebook** – Development environment

---

## Project Workflow

1. Loaded the dataset into Python.
2. Performed Exploratory Data Analysis (EDA) to understand trends and distributions.
3. Cleaned the data by handling missing values, duplicates, and inconsistent formats.
4. Imported the cleaned dataset into SQL and executed analytical queries.
5. Connected SQL/Excel data to Power BI.
6. Designed an interactive dashboard with KPIs and visualizations.
7. Created a professional presentation using Gamma to summarize findings and recommendations.

---

## How to Run

1. Clone this repository.
2. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Open the Jupyter Notebook and run all cells.
4. Import the cleaned dataset into your SQL database.
5. Execute the SQL queries provided in the project.
6. Connect the SQL database or Excel file to Power BI and refresh the dashboard.
7. Review the Gamma presentation for the project summary and business recommendations.
